Landing page AJM Technika (Namysłów) — pompy ciepła, klimatyzacja, kotły i rekuperacja.

Brief personalizacji: `PERSONALIZACJA.md`.

## Development

Potrzebujesz Node.js i npm — [instalacja przez nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

```sh
npm run build
npm run preview
```
